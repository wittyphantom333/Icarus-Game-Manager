# Nexus Mods Integration Guide

The Icarus Game Manager integrates with Nexus Mods to provide access to additional community mods. Due to Nexus Mods' terms of service, downloads require manual interaction.

## How Nexus Mod Installation Works

### 1. Browse Available Mods
- The system displays **10 curated Nexus mods** alongside **79 GitHub mods**
- All mods are verified and real (no fake or placeholder mods)
- Nexus mods are marked with an orange "Manual Download" indicator

### 2. Install a Nexus Mod
When you click "Install Mod" on a Nexus mod:

1. **Information Dialog**: Shows manual download instructions
2. **Auto-Open Page**: Automatically opens the mod's Nexus Mods page
3. **User Downloads**: You download the mod manually (free Nexus account required)
4. **Local Installation**: Return to the game manager and use "Install Local Mod File"

### 3. Supported File Types
- `.pak` files (most common for Icarus mods)
- `.zip` files (automatically extracted)
- `.EXMODZ` files (auto-converted from GitHub mods)

## Why Manual Download?

- **Terms of Service**: Nexus Mods requires user interaction for downloads
- **Premium Features**: Direct API downloads are limited to premium members
- **Security**: Manual verification ensures you're downloading the intended files
- **Account Benefits**: Free Nexus accounts get access to all mods
